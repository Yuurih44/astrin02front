# Astro Security

Primeira versão do site de apresentação. Projeto separado do Astro banco.

## Rodar

Node20 ou superior, sem instalar dependências:

```sh
npm run dev
```

Abra http://localhost:4180. `ASTRO_PORT` e `ASTRO_HOST` são opcionais; padrão127.0.0.1.

## Verificar

```sh
npm test
npm run check
```

Three.js0.170 e Manrope são servidos localmente, com licenças em public/vendor. Logo Astro fornecida pelo projeto do usuário. A cena3D é procedural e original: não depende de modelos ou serviços externos.

Contato gera arquivo de briefing local, sem envio ou armazenamento. Integrar canal real após definição pela equipe. Validar disponibilidade dos serviços, conteúdo comercial e termos antes de publicar. O relatório é demonstrativo e nenhum teste de vulnerabilidade é executado pelo site.
